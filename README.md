# ecommerce-sales-powerbi-dashboard
End-to-end e-commerce data analytics pipeline: Python (Pandas) data auditing &amp; feature engineering, PostgreSQL warehousing via SQLAlchemy, star-schema modeling, and interactive Power BI dashboarding with advanced DAX metrics.
